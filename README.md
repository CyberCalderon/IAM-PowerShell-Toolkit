# IAM-PowerShell-Toolkit
PowerShell automation for Active Directory and Microsoft Entra ID identity reporting, audit support, and access review workflows.

## Use Cases

- Active Directory stale user and computer reporting
- Privileged group membership review
- Microsoft Entra ID user inventory
- Conditional Access policy export
- Enterprise application audit support
- Access review preparation and audit evidence collection

## Project Structure

| Folder | Purpose |
|---|---|
| src | PowerShell scripts organized by function |
| tests | Pester tests for script validation |
| docs | Usage notes and security guidance |
| samples | Fake sample input/output data |

## Security Notes

This repository does not contain real company data, tenant data, credentials, secrets, logs, or production exports. Sample files use fake data only.
